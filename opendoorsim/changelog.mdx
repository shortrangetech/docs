This changelog tracks all notable changes to OpenDoorsim across hardware revisions, firmware updates, and companion software releases. It follows the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format — entries are grouped by version and categorized as **Added**, **Improved**, or **Fixed**.

<Note>
  OpenDoorsim is pre-1.0 software. Breaking changes may occur between minor versions. Review the release notes carefully before upgrading, and check the migration notes for any changes that affect existing workflows or data formats.
</Note>

## v0.3.0 — Latest

**Released:** Coming soon

- **Added:** Custom simulation profile support in companion app — define and save named door behavior profiles for repeatable test scenarios.
- **Added:** JSON export format alongside CSV, providing a more structured option for downstream data processing and integrations.
- **Improved:** Load cell calibration wizard accuracy, reducing zero-offset drift and improving consistency across calibration sessions.
- **Fixed:** Encoder angle rollover bug at 360 degrees that caused incorrect readings when the door completed a full rotation.

## v0.2.0

- **Added:** Reed switch open/close state detection, enabling discrete door-position events in addition to continuous angle data.
- **Added:** Session recording and playback, allowing full sensor sessions to be saved and replayed in the companion app for analysis.
- **Improved:** Arduino firmware stability under continuous sampling — resolved memory fragmentation issues that caused intermittent hangs during long-running sessions.
- **Fixed:** Serial connection drop after 30 minutes caused by a USB keep-alive timeout that was not being reset correctly.

## v0.1.0 — Initial Release

- Initial hardware design for a freestanding door frame simulator, including a bill of materials and fabrication guide.
- Basic Arduino firmware for hall effect sensor and rotary encoder data acquisition.
- Companion app featuring a live dashboard for real-time angle and force visualization.
- CSV data export for post-session analysis in spreadsheet tools.
