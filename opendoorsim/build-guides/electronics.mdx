This guide covers mounting and wiring the sensors that capture door motion, position, and force for the OpenDoorsim software. Each sensor feeds real-time data to an Arduino microcontroller, which streams it to the companion desktop application for visualization, logging, and simulation playback. Complete the [frame build](/opendoorsim/build-guides/frame) before starting this phase.

## Sensor Overview

OpenDoorsim uses four sensor types working together to produce a complete picture of door behavior:

| Sensor | Role |
|---|---|
| **Hall Effect (×2)** | Detects door proximity to the frame — measures how close the door edge is to the front and rear of the doorway. |
| **Rotary Encoder** | Mounts at the hinge axis to track precise hinge angle throughout the door's arc of travel. |
| **Reed Switch (×2)** | Binary open/closed state detection — one switch triggers at the fully-open position, the other at fully-closed. |
| **Load Cell + HX711** | Mounted in the door handle area to measure push and pull force applied by the user during simulation. |

## Wiring the Arduino

Connect each sensor to the Arduino using the pin assignments in the table below. Use the shortest practical wire runs and secure cables to the frame with cable clips to avoid tangling with the door swing.

| Sensor | Arduino Pin | Notes |
|--------|-------------|-------|
| Hall Effect #1 | D2 | Front proximity |
| Hall Effect #2 | D3 | Rear proximity |
| Rotary Encoder A | D4 | Quadrature signal A |
| Rotary Encoder B | D5 | Quadrature signal B |
| Reed Switch #1 | D6 | Fully open position |
| Reed Switch #2 | D7 | Fully closed position |
| HX711 DOUT | D8 | Load cell data |
| HX711 SCK | D9 | Load cell clock |

The following pin definitions are used throughout the OpenDoorsim firmware. You can reference or modify them in the firmware source:

```cpp arduino_pins.ino
// OpenDoorsim — Pin Definitions
#define HALL_FRONT 2
#define HALL_REAR  3
#define ENC_A      4
#define ENC_B      5
#define REED_OPEN  6
#define REED_CLOSE 7
#define HX711_DT   8
#define HX711_SCK  9
```

## Mounting and Wiring Steps

<Steps>
  <Step title="Mount Hall Effect Sensors on Door Edge and Frame">
    Attach one hall effect sensor to the **door edge** and its paired magnet to the **frame upright** (or vice versa), positioning them directly opposite each other with a **2–3 mm air gap** when the door is in the measurement position. Repeat for the second hall effect pair on the opposite side of the door. Use M2 screws or strong adhesive mounting tape rated for the sensor body. Route sensor wires along the frame upright toward the Arduino enclosure.
  </Step>

  <Step title="Mount Rotary Encoder on Hinge Pin">
    Fabricate or 3D-print a small bracket that clamps the rotary encoder body to the **top hinge barrel**, with the encoder shaft aligned coaxially with the hinge pin. The encoder shaft should rotate in sync with the door as it swings. Secure the bracket with M3 screws and confirm the encoder rotates freely without binding through the full range of door motion.
  </Step>

  <Step title="Attach Reed Switches to Frame and Door">
    Mount one reed switch on the **top of the frame header** and its magnet on the top edge of the door — positioned so they align when the door is **fully open**. Mount the second reed switch and magnet pair so they align when the door is **fully closed** (latch side, near the strike plate). Verify each switch activates with an audible click or a multimeter continuity test before securing the wiring.
  </Step>

  <Step title="Mount Load Cell Bracket on Door Handle Area">
    Using the load cell mounting bracket from the bill of materials, attach the load cell to the door face in the **handle area**, aligned along the axis of typical push/pull force. Secure the bracket plate to the door with the provided hardware. Thread the load cell cable along the door edge and through a strain-relief clip at the hinge side so the cable loops loosely enough to accommodate the full door swing without pulling taut.
  </Step>

  <Step title="Connect All Sensors to Breadboard / Arduino">
    Seat the Arduino Uno on the breadboard (or in the project enclosure). Connect each sensor's signal wire to the designated Arduino pin per the wiring table above. Connect all sensor **GND** leads to a common ground rail, and all **VCC** leads (3.3 V or 5 V as specified per sensor datasheet) to the appropriate power rail. The HX711 module connects DOUT → D8 and SCK → D9; power the HX711 from the 5 V rail.
  </Step>

  <Step title="Power Up and Verify Readings in Arduino Serial Monitor">
    Before flashing the full firmware, upload a simple pin-read sketch to the Arduino and open the **Serial Monitor** at 9600 baud. Manually trigger each sensor — wave a magnet past the hall effect sensors, rotate the encoder by hand, actuate the reed switches, and press on the load cell — and confirm that the corresponding Serial Monitor output changes as expected. This validates all connections before full integration.
  </Step>
</Steps>

<Warning>
  **Double-check polarity on all power connections before powering on.** Reversing VCC and GND on the HX711 or the hall effect sensors can permanently damage the ICs. Use a multimeter to verify voltage at each power pin against the sensor datasheet before connecting the USB cable to the Arduino for the first time.
</Warning>
