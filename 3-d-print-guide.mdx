The following print instructions and settings are what are used for the official ASA-CF cases. You may try to use materials other than ASA-CF, however, please note that you will definitely need to change the settings if you are using a different material.

## Slicer Settings

The slicer settings we use are found below.

### Print Settings

| Print Setting | Value |
| --- | --- |
| Layer Height | 0.2mm |
| Perimeters | 3 |
| Seam Position | Random |
| Infill | 15% |
| Fill Pattern | Gyroid |

### Temperature Settings

| Temperature Setting | Value |
| --- | --- |
| Nozzle, First Layer | 265 C |
| Nozzle, Other Layers | 265 C |
| Bed | 110 C |
| Chamber, Nominal | 55 C |
| Chamber, Minimal | 40 C |

### Cooling Settings

| Cooling Setting | Value |
| --- | --- |
| Bridges Fan Speed | 30% |
| Disable fan for the first | 5 layers |

### Modifiers

I place small modifier cubes around the following locations to help print stability and durability:

| Location | Setting |
| --- | --- |
| Threaded Insert Holes, Surrounding Area | Cube, 100% Infill |
| Screw Head Holes, Surrounding Area | Cube, 100% Infill |
| USB-C Hole | Cube, Support Enforcer |
| Thin PCB Slot Below USB-C Hole, Internal | Cube, Support Enforcer |
| Through Strap "C" Slots, Surrounding and Supporting Areas | Cube, 100% Infill |
| Velcro Strap Slots | Cubes, Support Enforcer |
