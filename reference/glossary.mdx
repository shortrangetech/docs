This glossary defines the key terms used throughout the OpenDoorsim documentation, covering hardware components, sensor types, and software concepts. If you encounter an unfamiliar term anywhere in the docs, this is the place to look it up.

| Term | Definition |
|------|------------|
| Arduino Uno | An open-source microcontroller board used as the OpenDoorsim data acquisition hub |
| Hall Effect Sensor | A sensor that detects magnetic fields; used to detect door proximity in OpenDoorsim |
| HX711 | A 24-bit ADC amplifier module used to read load cell (force sensor) data |
| Load Cell | A transducer that converts force/weight into an electrical signal; measures push/pull force on the door |
| Rotary Encoder | A sensor that converts rotational position to a digital signal; measures door hinge angle |
| Reed Switch | A magnetically-activated switch; used to detect fully-open and fully-closed door states |
| PPR | Pulses Per Revolution — the resolution of a rotary encoder |
| COM Port | The serial communication port on Windows used to connect to the Arduino |
| Baud Rate | The speed of serial communication between Arduino and PC, typically 115200 bps |
| Sample Rate | How many sensor readings per second the firmware captures (default: 50 Hz) |
| Session Profile | A named configuration preset defining thresholds and test parameters for a simulation run |
| Companion App | The OpenDoorsim desktop application used to visualize sensor data and manage sessions |
| Calibration | The process of zeroing and scaling sensor readings to accurate real-world values |
| Bill of Materials (BOM) | The complete parts list for building an OpenDoorsim rig |
