## Build with OpenDoorsim

OpenDoorsim is a fully open-source door simulator platform designed for hobbyists, researchers, and accessibility engineers. You can source every component from the bill of materials, follow step-by-step build guides to assemble the frame and wire the electronics, and then configure and operate your simulator using the user manuals — all without any proprietary tooling or lock-in.
