The Short Range Technologies event calendar aggregates all upcoming workshops, meetups, roundtables, and conference appearances. Use this page as your central reference for staying connected with the community.

<Note>
  To add an event or propose a community gathering, open a GitHub Issue with the `event` label and include the event name, date, format, and a brief description.
</Note>

## Recurring Events

| Event | Frequency | Format | Notes |
|---|---|---|---|
| OpenDoorsim Build Workshop | Quarterly | In-person | Materials provided |
| Accessibility Sim Roundtable | Quarterly | Virtual | Open to all |
| Hardware Hackers Meetup | Monthly | In-person | Informal |
| Community Q&A | Monthly | Virtual | Open forum |

## How to Stay Informed

There are several ways to keep up with Short Range Technologies events:

- **Watch the GitHub repository** for announcements — new events are posted as pinned issues and release notes on the [OpenDoorsim GitHub repository](https://github.com/shortrangetechnologies/opendoorsim).
- **Join GitHub Discussions** — follow event announcements and community updates in the [Discussions tab](https://github.com/shortrangetechnologies/opendoorsim/discussions) of the OpenDoorsim repository.
- **Subscribe to release notifications** — enable GitHub watch notifications on the repository to receive event announcements directly in your inbox.

<Tip>
  Want to be notified of new events automatically? Enable **Watch → All Activity** on the [OpenDoorsim GitHub repository](https://github.com/shortrangetechnologies/opendoorsim) or subscribe to the [GitHub Discussions feed](https://github.com/shortrangetechnologies/opendoorsim/discussions) to stay up to date without manually checking this page.
</Tip>
